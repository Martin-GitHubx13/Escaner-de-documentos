# 📱 Scanner Web

Una aplicación web para celular inspirada en aplicaciones como CamScanner, diseñada para escanear documentos directamente desde el navegador.

## 🚀 Habre la pagina

**[Abrir Scanner Web](https://TU-USUARIO.github.io/TU-REPOSITORIO/)**

## ✨ Características

* 📷 Captura de documentos usando la cámara del celular.
* 📄 Escaneo de documentos desde el navegador.
* 🔍 Vista previa de las imágenes capturadas.
* 📱 Interfaz adaptada para dispositivos móviles.
* 🌐 No requiere instalar una aplicación.

## 🛠️ Tecnologías

* HTML5
* CSS3
* JavaScript
